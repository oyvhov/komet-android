# Komet 2.2.0 · Klokkeverkstaden

Opne Klokkeverkstaden på Talplaneten eller under **Utforsk → Klokka**.

- I **Leik** kan barnet dra i time- og minuttvisaren eller bruke knappane. Den digitale klokka følgjer med. Med eit hopp på tolv timar kan barnet sjå korleis same urskive viser til dømes 09:30 om morgonen og 21:30 om kvelden.
- I **Øv** vekslar barnet mellom å lese ei urskive og å stille visarane etter digital tid. Det er seks oppgåver per runde, med heile timar, halve timar, kvarter eller femminuttssteg. Tips, forklaringar og opplesing finst på nynorsk og bokmål.
- Stjernekartet har rolegare lys og tydelegare planetskilt. Utforsk har fargekoda oppgåvekort, og planetkorta og oppgåvene deler den nye fargepaletten.
- Montessori-verkstaden er fjerna frå appen.

Du kan hente oppdateringa i appen under **Foreldre → Innstillingar → Appoppdateringar → Sjekk no**. Android ber ein vaksen godkjenne installasjonen.
