# Komet 2.1.0 · Montessori og eit vakrare romeventyr

## Ny Montessori-verkstad

Eit eige val på stjernekartet opnar ein roleg, Montessori-inspirert verkstad med:

- Raude og blå talstenger frå 1 til 5.
- Teljepinnar frå 0 til 5, med ei tom nullboks.
- Talsporing frå 1 til 5.

Barnet vel arbeidet sjølv og kan gjere det fleire gonger, utan klokke eller poeng.
Alt finst på nynorsk og bokmål. Lærarrettleiinga i repoet skildrar ein liten skulepilot
med fysisk materiell og observasjonar; den digitale verkstaden er eit supplement.

## Laga for nettbrett

- Arbeidsmatte og rettleiing har kvar sin plass i Montessori.
- Store materialillustrasjonar i ståande format og tre illustrerte materialkort i liggjande format.
- Rakettløpet har ein illustrert meny med fire valkort og eigne svarfelt i liggjande format.
- Opne romkort viser illustrasjon og lesetekst ved sida av kvarandre på liggjande nettbrett.

## Lys, rørsle og lyd

Romkorta får metalliske rammer, mjukt lys og sveving. Raketten får lysande spor og motorflamme.
Knappar, dialogar og skjermovergangar er mjukare, med nye trykk-, opnings- og plasseringslydar.
Montessori har eit eige, roleg musikkspor på lågare volum.

Retta ein feil som kunne merke ei rett talstengerekkjefølgje som feil. Stor skrift og avslåtte
animasjonar er kontrollerte. Framgang og profilar blir bevarte når appen blir oppdatert.

## Oppdatering

APK-en bruker same Komet-signatur og har versjonskode 7. Appen sjekkar automatisk etter nye
utgåver, høgst éin gong kvar tolvte time. Ein vaksen vel nedlasting og godkjenner installasjonen.
Du kan også gå til **Foreldre → Innstillingar → Appoppdateringar → Sjekk no**.

98 einingstestar er kontrollerte lokalt. Lyd og yting på fysisk nettbrett og observasjonar i skulen
står framleis att.
