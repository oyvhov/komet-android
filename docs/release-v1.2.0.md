# Komet 1.2.0

Den største oppdateringa til no: to nye fag, skriving med fingeren og eit nytt utsjånad.

- **Nytt utsjånad.** Same romtema, men djupare fargar, blanke 3D-knappar og kvit spelskrift med kontur.
  Romkorta har fått sjeldanheitsrammer, og rangen er eit merke på figuren.
- **Skriv med kometen.** Spor bokstavar og tal med fingeren i rett strekrekkjefølgje, med startprikkar og piler.
  Store eller små bokstavar etter profilen.
- **Engelsk.** 21 nivå med fraser, fargar, tal, dyr, mat, kropp, familie, klede, ting og staving. Orda blir lesne
  høgt med engelsk stemme.
- **Verdsrommet.** 12 nivå om sola, månen, planetane, romfart og stjernehimmelen.
- **Utforsk og favorittar.** Finn oppgåvetypane barnet likar, på tvers av trinn, og legg dei til med eit hjarte.
- **Lagring etter kvart svar.** Ein runde som blir avbroten, kan haldast fram frå heimeskjermen.
- **Repetisjon.** Øvst på kartet for kvart fag dukkar det opp ein runde med det som er vanskeleg.
- **Barneskrift.** Oppgåvene bruker Andika, med «a» og «g» slik skulen lærer dei.

«Lesing» heiter no «Norsk». Framgang, profilar og stjerner blir verande.

Universal APK for Android 8 eller nyare. Har du Komet 1.1.0, kan du oppdatere under
Foreldre → Innstillingar → Appoppdateringar.
