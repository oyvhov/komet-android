# Komet 1.1.0

Komet kan no oppdatere seg sjølv.

- Foreldre → Innstillingar → Appoppdateringar viser om det finst ein ny versjon, med «Sjekk no»,
  nedlasting og installasjon.
- Komet ser etter ny versjon når appen blir opna, høgst to gonger om dagen. Det kan slåast av.
- Ein liten gul prikk på låsen på heimeskjermen fortel dei vaksne at ein ny versjon er klar.
- Før installasjon kontrollerer appen filstorleik, SHA-256, pakkenamn, versjon og signatur.
  Android spør alltid før noko blir installert.
- Namnefeltet rettar ikkje lenger namn automatisk.

Den einaste nettkontakten er oppdateringssjekken mot GitHub. Framgangen ligg framleis berre på eininga.

Universal APK for Android 8 eller nyare. Installer over Komet 1.0.0 for å behalde profilar og
stjerner. Versjon 1.0.0 har ikkje oppdateringsfunksjonen, så 1.1.0 må installerast manuelt éin gong.
