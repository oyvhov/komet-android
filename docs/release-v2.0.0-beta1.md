# Komet 2.0.0-beta1 · testutgåve

Første smakebit av Komet-eventyret. Framgang, profilar og stjerner blir verande.

- **Stjernekartet** er ny heimeskjerm: sola, ein planet for kvart fag, rakettbana, romkort og Utforsk.
  Dra for å sjå rundt, og raketten flyg dit du trykkjer.
- **Planetane** er stader å gå på, med eige landskap, sti med nivå, skilt og små innbyggjarar.
  Astronauten går til nivået du vel.
- **Eigen astronaut og roboten Bolt.** Lag astronauten i oppstarten eller frå profilmenyen på kartet.
  Bolt ønskjer velkomen og les nivånamn høgt.
- **Oppgåvene skjer på planeten**, og resultatet er ei feiring.
- **Musikk** for kartet, kvart fag og rakettløpet. Kan slåast av under Foreldre → Innstillingar.
- Fyller heile skjermen på mobil og nettbrett, ståande og liggjande.

Testutgåve: ikkje ferdig testa på ekte nettbrett. For å få ho gjennom appen, slå på «Testutgåver» under
Foreldre → Innstillingar → Appoppdateringar. Universal APK for Android 8 eller nyare.
