# Nivå og læringsflyt i Komet 2.0.0

## Vurdering

Klassesteg er eit startpunkt for val av oppgåver, ikkje ein test av evnene til barnet. Barn kan
vere komne ulikt langt i lesing, matematikk og engelsk. Utforsk og lettare nivå skal difor vere
tilgjengelege, og ein fullført runde skal gi framgang sjølv når barnet treng hjelp.

## Retta før denne releasen

| Problem i første romoppdragsutkast | Endring |
| --- | --- |
| Førskuleoppgåva kunne gi 5 + 5, med tal heilt opp til 20 blant svara | Pluss til 5, tre svaralternativ innanfor 0–5 og bilete frå start |
| Alle tekstoppdraga var åtte oppgåver lange | Fem for førskule, seks elles |
| Fyll til 20 kom før barnet hadde øvd på tiarvenner i oppdraga | Nytt nivå til 10; til 20 flytta til klasse 2 |
| Landingsmønster blanda fleire steg og tal til 30 | Hopp på 2 innanfor 0–20 |
| Tosifra tal gjekk rett over til kode med hundrarar | Nytt mellomnivå med tiarar og einarar og visuell hjelp |
| Svaralternativa kunne kome utanfor talområdet, også over 999 | Talgrenser per oppgåvetype og eigne testar |
| Anbefalingar byrja på førskule uansett valt klassesteg | Føretrekk valt trinn, så tidlegare grunnlag, så høgare trinn |

## Gjennomgang av faga

- **Matte:** eksisterande innhald går frå teljing og bilete til symbol, tekst, gonge og dele.
  Romoppdraga brukar desse ferdigheitene i korte situasjonar. Fleirtrinnsoppgåver kjem seinare.
- **Norsk:** bokstavlydar og sporingsoppgåver gir inngangar før ord og setningar. Opplesing skal
  støtte instruksjonen utan å røpe ordet i ei leseoppgåve. Bokstavbygging kan krevje hjelp sjølv
  om ordet berre har tre bokstavar; førskulemerking må ikkje tolkast som at alle femåringar kan det.
- **Engelsk:** lytting og biletval kjem før lesing, omsetjing og staving. Fraseoppgåver med skriftlege
  svar kan krevje vaksenhjelp for barn som ikkje les. Dette er eit vidare forbetringspunkt.
- **Verdsrommet:** bilete og enkle fakta kjem før storleikssamanlikning og planetrekkjefølgje.
  Faktaoppgåver må tolkast som kunnskapsøving, ikkje som mål på lesedugleik.

## Vidare kalibrering

- Observer barn med ulike forkunnskapar på faktisk nettbrett: forståing, lesing, trykkfelt og pausar.
- Vurder lyttestøtte til engelske frasealternativ for dei yngste utan å røpe svaret.
- Vurder øving basert på nyare resultat; dagens repetisjon bruker samla første-forsøkstal.
- Skil mellom fullføring og meistring i vidare anbefalingar. Ei stjerne betyr fullført og gir
  tilgang vidare, men er ikkje dokumentasjon på at barnet har lært ferdigheita.

Dette er ein kode- og innhaldsgjennomgang med automatiske kontrollar, ikkje ei pedagogisk
brukarundersøking. Nye sperrer, tidsfristar eller krav om feilfrie rundar er ikkje innførte.
