# Komet 2.0.0 · eit romeventyr fullt av læring

**For barn frå 5 til 9 år. Matte, norsk, engelsk og verdsrommet på nynorsk og bokmål.**

## ⬇ Last ned appen

### [Last ned Komet 2.0.0 — APK for Android](https://github.com/oyvhov/komet-android/releases/download/v2.0.0/Komet-v2.0.0.apk)

Éi installasjonsfil for både mobil og nettbrett. Krev **Android 8.0 eller nyare**.
Opne APK-fila og vel Installer. Android kan be om løyve til å installere frå nettlesaren.

**Har du Komet frå før?** Installer oppdateringa oppå appen. Ikkje avinstaller først.
Profilar, stjerner og framgang blir bevarte ved vanleg oppdatering.

## Utforsk, lær og send hjelpa til basen

Lag din eigen astronaut og reis med roboten Bolt. **128 nivå i fire fag** gir korte rundar,
varierte oppgåver og nye utfordringar etter kvart.

![Stjernekartet i Komet](https://raw.githubusercontent.com/oyvhov/komet-android/v2.0.0/docs/images/v2.0.0/stjernekart.png)

- **Matte:** telling, rekning, klokke, pengar, mønster, gonge og dele.
- **Norsk:** bokstavar, lydar, rim, ord, lesing og skriving med fingeren.
- **Engelsk:** ord og fraser med engelsk opplesing, bilete og staveoppgåver.
- **Verdsrommet:** sola, månen, planetane og romfart, med romkort å samle.

## Nytt i denne utgåva

- **Tolv romoppdrag med Bolt:** samle krystallar, fyll raketten, reparer robotar og knekk kodar.
- **Barnet styrer utsendinga:** romskip, flygeboge, lyshale, landingsglitter og lyd. Basen får lys etter kvart.
- **Eigne landskap:** krystallar, energistasjon, robotverkstad, kodeportal, romhage og bru.
- **Jamnare vanskegrad:** bilete og tal til 5 først, tiarvenner før 20 og tosifra kodar før 999.
- **Korte oppdragsrundar:** fem oppgåver for dei yngste, seks i dei andre romoppdraga.
- **Anbefalingar etter valt klassesteg**, med fri utforsking og lettare øving framleis tilgjengeleg.
- **Stjernekart, astronautbyggjar, Bolt, musikk og butikk med spelepengar**, frå 2.0-testutgåvene.

## Auto update: appen finn nye versjonar

Komet **sjekkar automatisk etter oppdateringar** når appen kjem fram, høgst éin gong per tolv
timar. **Ein vaksen godkjenner nedlasting og installasjon.** Ingenting blir installert i bakgrunnen.

1. Opne **Foreldre → Innstillingar → Appoppdateringar**.
2. Trykk **Sjekk no** for å sjekke med ein gong.
3. Vel **Last ned oppdatering**, og så **Installer oppdatering**.
4. Gi løyve til å installere frå Komet dersom Android spør.

Appen kontrollerer storleik, SHA-256, pakkenamn, versjon og signatur før installasjon.
Automatisk sjekk kan slåast av. **2.0.0 er ei vanleg utgåve; testutgåver treng ikkje vere på.**

## Trygt og roleg å øve

Ingen reklame, ingen konto, ingen kjøp i appen og ingen sporing. Læringsinnhaldet fungerer utan
nett; oppdateringar krev nett. Norsk og engelsk talemotor på eininga gir opplesing.
Vanlege rundar har ingen tidsfrist og ingen liv å miste. Feil gir hjelp og nye forsøk.

**Testing:** 94 einingstestar, kontroll av 12 000 genererte romoppgåver, releasebygg og lint.
Kontrollert på emulator i mobil- og nettbrettformat med stor skrift og redusert rørsle.
Testing på fysisk nettbrett står att.
