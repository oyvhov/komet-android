**Jorda har fått eit atlas.** Vel Jorda → Geografi for å spele på trinnet ditt, frå førskule til 3. klasse. Finn flagg og hovudstader, kjenn att verdsdelar og hav, eller styr seglbåten til rett kai ved å trykkje på sjøkartet.

**Tre nye verkstader** ventar mellom planetane. Tyd romspråket i Stjerneposten på Uranus, del pizzaen på Venus og programmer Mars-roveren. Klokkeverkstaden finn du på Saturn.

Dra mellom dei åtte planetane eller hopp rett til ein planet frå Kartoversikt. Samle stempel i reisepasset og hjelp dei fire innbyggjarane med oppdrag som endrar heimstaden deira.

Barnet kan spele utan nett. På liggjande nettbrett får kart og oppgåve plass ved sida av kvarandre. Oppgåvene finst på nynorsk og bokmål.

Oppdater ei installert utgåve frå Foreldre → Innstillingar → Appoppdateringar → **Sjekk no**.
